DISABLED TESTS - External Scanner Implementation Issues
================================================================================

These tests have been disabled due to unresolved issues with the external scanner
implementation attempted on 2025-10-11. The external scanner was meant to
disambiguate line blocks from pipe tables, but it introduced parsing failures
in multiple constructs.

See EXTERNAL_SCANNER_PLAN.md for full implementation details and analysis.
